# Smart Job Application Tracker with Interview Prep
> *IT314 Software Engineering Project*

Cohort is a web application that helps students track job applications, log interview rounds, and prepare with personalized question mastery and privacy-preserving federated intelligence.

### 🛠️ Tech Stack
- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS
- **Backend**: Java 21, Spring Boot 3.5, PostgreSQL 16
- **AI/ML**: Python 3.12, FastAPI, Flower (Federated Learning)
